# Сертификат «Savo Dev» для стабильной подписи

Без сертификата build.sh подписывает бандл ad-hoc: приложение работает,
но macOS считает каждую пересборку «новым» приложением. С самоподписанным
сертификатом подпись стабильна между сборками.

Создание (один раз на каждом Mac):

1. Открыть «Связку ключей» (Keychain Access).
2. Меню: Связка ключей → Ассистент сертификации → Создать сертификат…
3. Имя: `Savo Dev`
4. Тип идентификации: Самоподписанный корневой сертификат.
5. Тип сертификата: Подпись кода (Code Signing).
6. Создать → Готово.

Проверка, что сертификат виден codesign:

```bash
security find-identity -v -p codesigning | grep "Savo Dev"
```

После этого `./build.sh` подпишет бандл сертификатом автоматически.
Другое имя сертификата можно передать через переменную окружения:

```bash
SAVO_SIGN_ID="Моя подпись" ./build.sh
```

На чужом Mac сертификат неизвестен — Gatekeeper заблокирует первый запуск:
правый клик по Savo.app → «Открыть», либо Системные настройки →
Конфиденциальность и безопасность → «Открыть всё равно».
